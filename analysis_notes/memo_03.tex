\section*{Purpose}
This memo records the latest 10-day comparison of cases \texttt{a},
\texttt{b}, and \texttt{c}, and updates the diagnostic hypotheses after the
recent improvement to the split-field \texttt{conc}/\texttt{cnew} update before
processor exchange.  The main target is the null-floc comparison:
\texttt{conc} in case \texttt{a} should match \texttt{conc\_d} in case
\texttt{b} when the kinetic interaction terms and aggregation fractions are
zero.

\section*{Cap and Split Checks}
The hard cap is no longer a leading explanation for this 10-day test.  The
largest extracted concentrations are far below the code cap of
\(100~\mathrm{kg\,m^{-3}}\):
\[
\max C_a = 4.43\times 10^{-4}, \qquad
\max C_b = 6.98\times 10^{-3}, \qquad
\max C_c = 1.45\times 10^{-2}~\mathrm{kg\,m^{-3}}.
\]
The cap-threshold counters are zero for all split variables in cases
\texttt{b} and \texttt{c}.  The cap code remains present in
\texttt{mod\_plast.F:1242--1243}, but the present output indicates it is not
active.

The saved split fields are internally consistent:
\[
\texttt{mp1\_agg}+\texttt{mp1\_dis}\approx\texttt{mp1}.
\]
The maximum total split-minus-combined mismatch is zero for case \texttt{b}
and \(1.83\times10^{-7}~\mathrm{kg}\) for case \texttt{c}.  Therefore the
saved-output recombination is not the present sink.

\section*{Coding Symmetry Check}
The static setup is mostly symmetric.  In \texttt{init\_plast.F:200--208},
\texttt{INI\_CONC\_AG\_RATE=0} initializes
\(\texttt{conc\_a}=0\), \(\texttt{conc\_d}=\texttt{conc}\), and matching
\texttt{cnew\_a}/\texttt{cnew\_d}.  The generic plastic input files also match
except for \texttt{PLAST\_FLOC}: source aggregation, initial aggregation, mass
aggregation, and OBC aggregation are all zero.

The main remaining code-path differences are:
\begin{enumerate}
\item \textbf{Runtime namelist asymmetry.} Case \texttt{a} uses
\texttt{SEDIMENT\_MODEL=F}, while case \texttt{b} uses
\texttt{SEDIMENT\_MODEL=T}.  This means the two cases are not only
\texttt{PLAST\_FLOC=F} versus \texttt{PLAST\_FLOC=T}; they also enter
different compiled/runtime sediment branches.

\item \textbf{Transport is one combined tracer versus two split tracers.}
Case \texttt{a} calls \texttt{adv\_scal} once on \texttt{conc}
(\texttt{mod\_plast.F:1261--1267}).  Case \texttt{b} calls \texttt{adv\_scal}
first on \texttt{conc\_a} and then on \texttt{conc\_d}
(\texttt{mod\_plast.F:1166--1183}).  With
\texttt{SOURCE\_AG\_RATE=0}, the \texttt{conc\_d} source should equal the
combined source, but the split path still performs an extra zero-tracer pass
for \texttt{conc\_a}.

\item \textbf{Vertical diffusion is also split.} The floc path calls
\texttt{vdif\_scal} on \texttt{cnew\_a} and \texttt{cnew\_d}
(\texttt{mod\_plast.F:1202--1204}); the no-floc path calls it once on
\texttt{cnew} (\texttt{mod\_plast.F:1276--1278}).  In exact arithmetic this
should be equivalent when \texttt{cnew\_a}=0, but it is still a checkpoint
for roundoff, wet/dry, and halo-state differences.

\item \textbf{Open-boundary and point-source boundary conditions are split.}
The floc path applies OBC and point-source boundary calls separately to
\texttt{conc\_a}/\texttt{conc\_d}
(\texttt{mod\_plast.F:1543--1554} and
\texttt{mod\_plast.F:1600--1605}); the no-floc path applies them once to
\texttt{conc} (\texttt{mod\_plast.F:1563--1568} and
\texttt{mod\_plast.F:1612--1614}).  Because \texttt{OBC\_AG\_RATE=0} and
\texttt{SOURCE\_AG\_RATE=0}, \texttt{conc\_d} should receive the full
boundary/source value, but this remains a leading place to compare
post-operator mass.

\item \textbf{The first MPI exchange still exchanges combined \texttt{cnew}
in the split branch.} Before OBC handling, the floc branch exchanges
\texttt{cnew\_a}, \texttt{cnew\_d}, and \texttt{cnew}
(\texttt{mod\_plast.F:1513--1516}).  At that point the meaningful updated
state is split; combined \texttt{cnew} is not rebuilt until
\texttt{mod\_plast.F:1715--1716}.  This may be harmless if no code consumes
combined \texttt{cnew} in between, but it is not strictly symmetric and should
be cleaned or checkpointed.

\item \textbf{Final exchange/recombination was improved but should remain an
invariant check.} The split path now clips \texttt{cnew\_a}/\texttt{cnew\_d},
exchanges those same arrays, then rebuilds
\(\texttt{conc}=\texttt{cnew}=\texttt{conc\_a}+\texttt{conc\_d}\)
(\texttt{mod\_plast.F:1657--1716}).  The mass recovery in case
\texttt{b} supports this as a real previous asymmetry.

\item \textbf{Bed/surface update is algebraically different but inactive for
case \texttt{b}.} The floc branch splits erosion and surface input by
\texttt{ratio\_bottom}/\texttt{ratio\_surface} and applies a 10x growth limiter
(\texttt{mod\_plast.F:2383--2440}); the no-floc branch adds directly to
\texttt{conc} (\texttt{mod\_plast.F:2451--2461}).  However, the extracted
case-\texttt{a}/\texttt{b} bed mass and sampled dep/ero integrals are zero, so
this is not the leading explanation for the current \texttt{a}/\texttt{b}
gap.
\end{enumerate}

\section*{Updated Hypotheses}
\begin{enumerate}
\item \textbf{Leading hypothesis: transport/OBC/source operator asymmetry.}
Since the cap is inactive and bed exchange is zero for case \texttt{b}, the
remaining mass deficit most likely appears between \texttt{adv\_scal},
\texttt{vdif\_scal}, \texttt{bcond\_scal\_OBC}, \texttt{bcond\_scal\_PTsource},
and the final nonnegative clamp/exchange.  A checkpoint budget after each of
these operators should show the first divergence.

\item \textbf{Configuration asymmetry must be isolated.} A true symmetry test
should compare no-floc and null-floc runs with the same
\texttt{SEDIMENT\_MODEL} setting.  The cleanest next pair is an
\texttt{a\_sedT} case using \texttt{PLAST\_FLOC=F} and
\texttt{SEDIMENT\_MODEL=T} versus the current null-floc case \texttt{b}.

\item \textbf{Hard cap is demoted for this run.} The cap remains a real
non-conservative code site, but current maxima and threshold counts show it is
not active in the present 10-day outputs.

\item \textbf{Nonnegative clipping remains possible.} The current extraction
tracks cap counts and negative saved mass, but it does not measure mass
removed internally by \texttt{max(...,0)} before output.  This is still a
plausible silent sink if the split transport path produces transient negative
undershoots that are clipped before the saved time slice.

\item \textbf{Bed-exchange and erosion/surface limiters are secondary for the
case-\texttt{a}/\texttt{b} mismatch.} They remain important for case
\texttt{c} and full floc interaction, but the present null-floc case
\texttt{b} has zero final bed mass and zero sampled dep/ero exchange.
\end{enumerate}

\section*{Focused Next Test}
\begin{enumerate}
\item Run a matched \texttt{SEDIMENT\_MODEL=T}, \texttt{PLAST\_FLOC=F}
baseline.  If this aligns with case \texttt{b}, the current difference is
mostly a sediment-runtime comparison issue.  If it aligns with case
\texttt{a}, the split path remains the cause.

\item Add a short internal checkpoint diagnostic for one small run.  Record
domain-integrated mass for \texttt{conc}, \texttt{conc\_d}, and
\(\texttt{conc\_a}+\texttt{conc\_d}\) after: start, deposition, erosion/surface
update, \texttt{adv\_scal}, \texttt{vdif\_scal}, OBC, point-source BC,
nonnegative clamp, MPI exchange, and recombination.

\item For the same diagnostic, explicitly accumulate mass removed by
nonnegative clipping and the hard cap.  The cap should remain zero in this
test; any nonzero clipping loss would be immediately informative.

\item If serial and parallel runs differ, focus on the two exchange locations:
\texttt{mod\_plast.F:1513--1516} before OBC and
\texttt{mod\_plast.F:1677--1716} at the final split recombination.
\end{enumerate}
