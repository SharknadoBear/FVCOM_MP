\section*{Purpose}
This memo updates the MP1 mass-conservation diagnosis after the new case
\texttt{a} test in which sediment runtime was active from the beginning of the
run, but the sediment horizontal \texttt{adv\_scal\_backward} and
\texttt{fct\_sed} block in \texttt{mod\_sed.F} was bypassed.  The new result is
the strongest evidence so far: case \texttt{a} returns to the old
\texttt{v001}/\texttt{v004}-like mass behavior when that sediment advection/FCT
stage is closed.

\section*{Relevant Call Trace}
\begin{enumerate}
\item \textbf{Setup order.} In \texttt{fvcom.F:643--651},
\texttt{SETUP\_SED} is called before \texttt{SETUP\_PLAST}.

\item \textbf{Timestep order.} In \texttt{internal\_step.F:1092--1137},
\texttt{ADVANCE\_SED} is called before \texttt{ADVANCE\_PLAST}.  Plastic
therefore sees whatever state sediment leaves behind each internal step.

\item \textbf{Sediment startup guard.} In \texttt{mod\_sed.F:883},
\texttt{Advance\_Sed} returns immediately when \texttt{iint < sed\_start}.  The
\texttt{v004} test used this to keep sediment setup active while removing
active sediment runtime.

\item \textbf{Bypassed block in the current build.} In
\texttt{mod\_sed.F:1016--1033}, the sediment
\texttt{adv\_scal\_backward} call and \texttt{fct\_sed} limiter are commented,
while \texttt{sed(i)\%cnew = sed(i)\%conc} and
\texttt{sed(i)\%cflx = 0.0\_sp} keep the rest of \texttt{Advance\_Sed} moving.

\item \textbf{Shared scalar machinery.} \texttt{Adv\_Scal\_Backward} begins at
\texttt{mod\_scal.F:648}.  During that routine, bottom scalar-gradient arrays
\texttt{PFPXB}/\texttt{PFPYB} are written at
\texttt{mod\_scal.F:911--912}.  This remains a concrete shared-state candidate,
although the current test only proves that the sediment
\texttt{adv\_scal\_backward}/\texttt{fct\_sed} stage is implicated, not which
line inside the stage is responsible.
\end{enumerate}

\section*{Diagnosis}
\begin{enumerate}
\item \textbf{The problem is no longer just ``sediment runtime on''.}
\texttt{v002} and \texttt{v003} showed that active sediment runtime could move
case-\texttt{a} final domain MP1 mass from about \(1001~\mathrm{kg}\) down to
\(573\)--\(582~\mathrm{kg}\).  \texttt{v004} then showed this was not caused by
sediment setup, sediment namelist presence, or the sediment-enabled river
forcing path, because delaying active \texttt{Advance\_Sed} recovered the old
mass curve.

\item \textbf{The new smoking gun is the sediment horizontal
advection/FCT stage.} \texttt{v005} keeps active sediment runtime, starts
sediment immediately, and keeps the non-advection parts of
\texttt{Advance\_Sed} active.  Closing only the sediment
\texttt{adv\_scal\_backward}/\texttt{fct\_sed} block recovers the
\texttt{v001}/\texttt{v004}-like case-\texttt{a} result.  That makes this block
the leading source of the unwanted sediment/plastic interaction.

\item \textbf{The effect is probably not intended floc physics.} Case
\texttt{a} has \texttt{PLAST\_FLOC=F}; no-floc plastic should not depend on
sediment concentration, sediment size, or sediment settling velocity through the
floc-rate routines.  A no-floc response to sediment horizontal transport points
toward shared scalar-transport state, altered boundary/source handling, or
another side effect left behind before \texttt{Advance\_Plast} runs.

\item \textbf{BBL roughness stays demoted.} The \texttt{v003} BBL-off run was
only \(9.13~\mathrm{kg}\) lower than the \texttt{v002} BBL-on run, while both
were more than \(410~\mathrm{kg}\) lower than \texttt{v005}.  BBL roughness is
not the leading explanation for the present case-\texttt{a} mass shift.

\item \textbf{The present-stage model should keep this sediment block closed.}
For the next plastic tests, the safest controlled configuration is the current
compiled source with the sediment \texttt{adv\_scal\_backward}/
\texttt{fct\_sed} block disabled in \texttt{mod\_sed.F}, while using identical
sediment input for cases \texttt{a}, \texttt{b}, and \texttt{c}.  Then the
remaining differences should be driven by the plastic configuration rather than
by different sediment input settings.

\item \textbf{The b/c outputs must be regenerated before interpreting the
remaining case differences.} The current \texttt{v005} live folder contains a
new case-\texttt{a} result, but cases \texttt{b} and \texttt{c} are still the
previous outputs.  They should be rerun with the same disabled sediment
advection/FCT build and the same sediment input now used by case \texttt{a}.
\end{enumerate}

\section*{Next Test Setup}
For the next run series, cases \texttt{b} and \texttt{c} should mirror the
case-\texttt{a} sediment setup exactly:
\begin{enumerate}
\item Keep the current \texttt{mod\_sed.F} build in which the sediment
\texttt{adv\_scal\_backward}/\texttt{fct\_sed} block is bypassed.
\item Use \texttt{SEDIMENT\_MODEL=T} for all three cases.
\item Point cases \texttt{a}, \texttt{b}, and \texttt{c} to the same sediment
input file, \texttt{mp\_sediment\_a\_no\_adv.inp}.  This file starts sediment
at \texttt{SED\_START = 1}, keeps suspended sediment active, and keeps BBL
roughness closures off.
\item Leave the plastic input files case-specific:
\texttt{generic\_plastic\_a.inp}, \texttt{generic\_plastic\_b.inp}, and
\texttt{generic\_plastic\_c.inp}.  This preserves the plastic behavior being
tested while removing sediment-input differences.
\end{enumerate}

\section*{Focused Follow-Up Checks}
\begin{enumerate}
\item Rerun cases \texttt{b} and \texttt{c} with the mirrored sediment input and
the present disabled sediment advection/FCT build.  Archive those outputs as the
next version before changing code again.

\item If a narrower code diagnosis is needed, split the current bypass into two
tests: re-enable \texttt{adv\_scal\_backward} with \texttt{fct\_sed} still
disabled, then test \texttt{fct\_sed} separately.  This separates transport
side effects from limiter side effects.

\item Add a targeted shared-state checksum immediately before and after
\texttt{Advance\_Sed}, before \texttt{Advance\_Plast}.  Track
\texttt{PFPXB}, \texttt{PFPYB}, \texttt{D}, \texttt{DT}, \texttt{DZ},
\texttt{KH}, \texttt{U}, \texttt{V}, boundary/source flux summaries, and the
shear-stress array passed to plastic.

\item Run a save/restore test around sediment \texttt{adv\_scal\_backward} for
candidate shared arrays.  If restoring one array recovers the
\texttt{v001}/\texttt{v004}/\texttt{v005}-like mass curve, the coupling
mechanism is identified directly.

\item For b/c, reconcile the sediment post-clipping exchange path.  After
sediment clipping, \texttt{mod\_sed.F:1099--1104} updates
\texttt{sed(i)\%conc}; the following MPI exchange at
\texttt{mod\_sed.F:1117--1122} exchanges \texttt{sed(i)\%cnew}, not the clipped
\texttt{sed(i)\%conc}.  That mismatch is a plausible source of rank-boundary
noise in floc cases because floc-rate calculations read
\texttt{sed(ised)\%conc}.
\end{enumerate}
